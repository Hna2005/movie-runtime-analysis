# Global Movie Runtime

A casual conversation about movie length sparked this project. I realized I had a strong intuition that "most movies are over three hours long." Rather than relying on intuition, I decided to explore the data and answer the question using real-world movie metadata.

## Goal

The goal of this project is to examine the relationship between movie **runtime** and various features such as budget, revenue, genre, release year, user ratings, and popularity, as well as to investigate which factors influence runtime.

## Limitations

- The dataset is not a complete record of all movies ever released.
- The latest movies included are from 2017.
- Results should be interpreted within the scope of this dataset.
